# MindSlot — Розумний простір для приватного психолога

Інтерактивний веб-MVP для приватних психологів без адміністратора.

## Що працює в MVP
1. **Кабінет психолога (`🧑‍⚕️`)**:
   - **Розклад і слоти**: додавання вільних вікон, підтвердження оплат в 1 клік, автоматичний **Лист очікування (Waitlist)** при скасуванні сесії.
   - **База клієнтів (Особисті картки)**: Біо/запит клієнта, історія міжсесійних чек-інів («167 годин між сесіями») та **приватні нотатки психолога**.
   - **Конструктор програм груп**: миттєва генерація покрокової програми групової терапії з таймінгом по хвилинах, вправами та «Планом Б».
   - **Налаштування сеттингу й оплати**: Monobank/IBAN, Zoom/Meet, увімкнення/вимкнення правила 24 годин.
2. **Екран клієнта (`🌿`)**:
   - Самозапис на вільний слот + заповнення Біо + оплата.
   - Самостійне перенесення/скасування з автоматичною перевіркою **Правила 24 годин**.
   - Швидкий **Чек-ін стану між сесіями**, який одразу з'являється у картці клієнта психолога.
3. **⚡ Симуляція нагадувань** у шапці: демонструє вживу нагадування клієнту за 24 год та «Шпаргалку психологу за 15 хв до сесії».

## Запуск локально
```bash
npm start
```
Відкрийте **http://localhost:3000** (або просто відкрийте файл `index.html` у браузері).
